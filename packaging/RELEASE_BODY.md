## Download & Start (Windows)
1. **`Transcripter-…-windows.zip`** herunterladen und in einen **lokalen** Ordner entpacken (nicht OneDrive).
2. `Transcripter\Transcripter.exe` doppelklicken. Eine Windows-Warnung beim ersten Start mit „Weitere Informationen → Trotzdem ausführen“ bestätigen.
3. Auf „Aufnahme starten“ klicken, danach auf „Aufnahme beenden“. Das Transkript entsteht automatisch und lässt sich per Doppelklick öffnen.

Alles läuft lokal, das Sprachmodell ist enthalten, und es werden keine Daten ins Internet gesendet.
Diese Version rechnet nur auf der CPU. Ein Paket für NVIDIA-Grafikkarten folgt.

Aufnahmen bitte nur mit Einverständnis aller Teilnehmer machen.
